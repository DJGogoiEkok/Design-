## 2026-07-29 - [CRITICAL] Fix Session Fixation Vulnerability\n**Vulnerability:** The admin login endpoint (`admin/login.php`) failed to regenerate the session ID upon successful authentication.\n**Learning:** This missing control allows for a Session Fixation vulnerability where an attacker could theoretically pre-set the session ID and hijack the admin's session after they log in. Always issue a fresh session ID during privilege elevation.\n**Prevention:** Added `session_regenerate_id(true);` immediately following successful credential verification, before marking the session as authenticated.
